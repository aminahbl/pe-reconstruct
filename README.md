# pe-reconstruct (Demo Site)

This is a demo presentation layer for composed Dīgha Nikāya texts with
peyyāla reconstructions outputted by the [arkiuat/pe-reconstruct](https://github.com/arkiuat/pe-reconstruct) utility.

This fork adds a simple website interface in `site/` for viewing the reconstructed texts. It does not develop the reconstruction automation itself, but just generates the static files which in turn are used to generate the website content hosted on GitHub Pages.

For project background and canonical upstream context, please see:

https://github.com/arkiuat/pe-reconstruct
